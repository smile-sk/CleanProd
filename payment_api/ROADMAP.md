# CleanTrade Payment API - роадмап

**Обновлено: 2026-08-20**

## Фаза 1 - MVP ✅
* POST /v1/orders (уникальная сумма 9.5x + кошелёк), GET /v1/orders/{id}, /healthz.
* Поллер TronScan (mock / реальный), вебхук с ретраями (до 3), статусы
  created → paid | expired.
* Деплой на VPS example-vps, `stablepay` (systemd, автозагрузка),
  HTTPS: pay.cleantrade.info (certbot, автопродление).

## Фаза 2 - собака ест свой корм ✅
* CleanTrail продаётся через этот API: бот = клиент API.
* /buy → POST /v1/orders → уникальная сумма → оплата → вебхук на локальный
  приёмник (127.0.0.1:8081) → автовыдача zip + токен.
* Один поллер (в API) вместо двух. Цена CleanTrail - 10 USDT.
* E2E проверено вживую на VPS (мок-заказ 9.54 → вебхук → токен админу).

## Фаза 2.5 - инфраструктура ✅
* CashAPI («API-аптека») переехала с NAS на VPS: контейнер cashapi
  (127.0.0.1:8001), apiteka.pp.ua через A-запись + certbot HTTPS.
* RapidAPI/Zyla не тронуты: домен и пути те же, проверено через прокси
  RapidAPI живьём (healthz, /v1/validate/email, /v1/uuid/v7, /v1/cidr - 200).

## Фаза 3 - продукт наружу (текущая)

### 3.1 Доки + лендинг - в работе (этот коммит)
* PRICING.md - тарифы зафиксированы: Free $0 / Starter $9.99 / Pro $29.99 / Business $79.99.
* Лендинг на pay.cleantrade.info: как работает, тарифы, пример curl.
* README обновлён.

### 3.2 Биллинг ✅
* Подписчики: ключи `sp_live_...` в `data/subscribers.json`, планы
  free(5)/starter(100)/pro(3000)/business(∞), лимиты заказов/мес.
* **402 Payment Required** при исчерпании лимита (анонсировано в PRICING).
* `POST /v1/subscribe` - публичная подписка: заказ plan:<тариф> → оплата USDT
  → активация плана → вебхук с `api_key` (догфуд по полной).
* `GET /v1/subscribers/me` - план/лимит/использовано.
* Страница `/subscribe.html` - форма: план + TG/email → оплата → ключ.
* Открыто: ЛК мерчанта с историей заказов и вебхук-логом (3.2.1), продление/отмена.

### 3.2.2 Ребрендинг ✅
* Stablecoin Payment API → **CleanTrade Payment API** (единая семья CleanTrade/CleanTrail).
* Домен: pay.apiteka.pp.ua → **pay.cleantrade.info** (DNS, certbot, apache vhost,
  301 с старого домена; RapidAPI base URL обновлён и перетестирован).

### 3.3 Каналы сбыта
* TG: чаты ботоделов, продавцов цифровых товаров, крипто-комьюнити.
  Кейс «CleanTrail продаётся через свой API» - готовый материал.
* Хабр/VC: статья «принимаю USDT в боте без платёжки за вечер».
* Партнёрская программа: % с подписок приведённых (после 3.2).
* RapidAPI - только витрина позже (крипта - мутная политика, вебхуки - боль).

### 3.4 (опционально)
* Pay-as-you-go (+2.5% к сумме заказа) - если спрос покажет.
* Разовая лицензия self-hosted для разработчиков.
