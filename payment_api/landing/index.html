A few lines of code

Create an order and get a unique amount:

curl -X POST https://pay.cleantrade.info/v1/orders \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"product_id":"my_product","wallet":"TRX_ADDRESS","webhook_url":"https://my.site/hook"}'

→ {"order_id":"abc123","amount":9.57,"wallet":"T...","status":"created"}
Every order is paid to the TRC20 wallet you pass in the request - the API returns that same address in the order. We take no percentage: we only confirm the payment and wake your server with a webhook.

FAQ

How does CleanTrade detect payments?

Each order gets a unique amount (e.g. 9.57 USDT), unique within that wallet. The buyer sends exactly that amount to your TRC20 address from the order. Our poller scans that address every 30 seconds; when a transfer with that amount arrives after the order was created, the order becomes paid and your webhook fires.

Where do the payments go?

To the TRC20 wallet you set in the order - we never hold the money and we do not open wallets for you. Two merchants can use the same amount, because matching is per wallet.

What are the fees?

No percentage. Free plan: $0 (up to 5 orders/month). Paid plans are flat subscriptions: Starter $9.99, Pro $29.99, Business $79.99 per month, or $99.90/$299.90/$799.90 per year (12 months for the price of 10).

Do I need KYC or registration?

No. Get an API key in about a minute - no documents, no business registration, no approval queue.

Which blockchain and token?

USDT on TRC20 (Tron). The buyer pays to the TRC20 address the API returned; no smart contracts and no extra gas for you.

How fast is payment detection?

The poller checks every ~30 seconds, so orders usually become paid within a minute of the transfer.

How is this different from @CryptoBot / Crypto Pay?

Both take USDT in a Telegram bot. The difference is the shape: @CryptoBot is a bot with its own internal balance and a Telegram UI; CleanTrade is a plain HTTP API that your own code drives - unique amounts, webhooks, auto-delivery. One honest note: with CleanTrade the money lands on your own wallet, exactly like a direct transfer - we only match it by the unique amount.

Why not self-host BTCPay Server?

BTCPay is free, powerful and non-custodial - if you want to run and maintain your own node. CleanTrade is the same idea as a managed API: no server, no chain-sync, no updates to babysit. You POST an order and we watch the chain and wake your webhook. If you already run infra and want full control, BTCPay is excellent; if you want a few lines of code and zero ops, CleanTrade is the shortcut.
